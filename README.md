# AI Voice Detector

AI Voice Detector is a comprehensive machine learning pipeline and microservices architecture designed to detect voice activity in audio streams.

## Structure
- ml/: Machine learning models, training scripts, and evaluation logic
- services/: Microservices for data ingestion, preprocessing, and prediction
- infra/: Infrastructure as code
- helm/: Helm charts for Kubernetes deployment
- docs/: Documentation and ADRs

## Deployment
See `.github/workflows` for CI/CD details.
